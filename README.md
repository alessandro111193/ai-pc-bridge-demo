# AI-PC Bridge — Demo pubblica

Anteprima statica di AI-PC Bridge: design nero e blu neon, robot animato e Mission Control interattiva.

**Questa è una simulazione**: chat, terminale, correzione, test e aggiornamenti della Control Room sono scenari dimostrativi nel browser. Non accede al computer del visitatore e non esegue comandi reali.

Questo repository contiene soltanto i file necessari al sito pubblico, non il codice operativo, le configurazioni o le credenziali di AI-PC Bridge.

Per la demo apri GitHub Pages dal link indicato nella sezione Pages del repository.
